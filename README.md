# Aryan Katiyar Website

This repository hosts a lightweight personal website designed for GitHub Pages.

## Structure

- `index.html`: homepage and introduction
- `blog.html`: blog landing page
- `research.html`: research interests and current directions
- `projects.html`: selected technical projects
- `cv.html`: web-first CV
- `posts/`: individual blog posts
  - includes general posts and book reviews
- `styles.css`: shared styling
- `script.js`: mobile navigation and reveal animations

## Publishing

Enable GitHub Pages for the repository and serve from the default branch root.

## Easy next upgrades

- Add a profile photo and replace the `AK` monogram on the homepage
- Add a PDF resume and link it from `cv.html`
- Add a blog page or a publications page as your work grows
