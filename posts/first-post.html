Setting up this blog section

April 14, 2026

This is a placeholder post, but it is also the first reusable pattern for future writing on the site.

I wanted the website to have a place for less formal writing alongside research and projects. That usually ends up being the most alive part of a personal site anyway.

For now, the blog is intentionally simple: static HTML posts, a landing page that lists them, and a shared visual style with the rest of the site. This keeps things easy to maintain on GitHub Pages while still giving me room to write about random things.

What could go here

The answer is basically anything with a point of view: thoughts on machine learning, notes from an internship, project postmortems, reading notes, football stories, or just a well-formed rant about something technical.

What changes later

If the blog grows, this can become a proper Jekyll-based collection with tags, dates, and automatic indexing. The current setup is a deliberately lightweight starting point rather than a dead end.
