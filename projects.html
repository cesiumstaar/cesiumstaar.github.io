Projects

Selected technical work

These projects span retrieval, speech, optimization, probabilistic reasoning, and financial systems. Together, they reflect the kind of work I enjoy most: mathematically structured problems with a strong implementation component.

IR Ranking NLP

Semantic Search and Hybrid Retrieval

Built retrievers across HotpotQA, WikiCLIR, and Quora using BM25, TF-IDF, BERT, and hybrid retrieval pipelines.

  • Implemented diversity-aware ranking with MMR, ILP, and LP relaxation
  • Developed a DeepImpact-style retriever with a BERT reranking stage
Speech Robustness Optimization

Adversarial Attacks on ASR

Studied targeted and robust attacks against Wav2Vec2 and Whisper-based systems with a focus on CTC objectives and expectation over transformations.

  • Explored transferability and black-box behavior
  • Analyzed convergence properties under stronger robustness constraints
Optimization Logic MILP

Weighted MaxSAT via MILP

Formulated MaxSAT as a mixed-integer optimization problem and solved it using Gurobi-backed MILP encodings.

  • Used McCormick linearization to handle bilinear structure cleanly
  • Focused on exactness, tractability, and clear constraint design
PGMs Inference Algorithms

Probabilistic Junction Tree Engine

Implemented a full inference engine with triangulation, clique extraction, and both sum-product and max-product message passing.

  • Built the pipeline from graph processing to exact inference
  • Worked through the data structures needed for efficient factor propagation
Web3 Systems Simulation

DEX Simulation and Arbitrage

Implemented Uniswap V2-style AMM contracts in Solidity and built simulation tooling to study arbitrage opportunities across multiple liquidity pools.

  • Modeled trading dynamics under realistic reserve updates
  • Connected protocol mechanics to strategy-level analysis
Market Data Anomaly Detection ML

High-Frequency Order Book Modeling

Designed feature pipelines on NSE TBT data to distinguish algorithmic and retail activity and to isolate short-horizon predictive signals.

  • Used logistic regression, GBDTs, SVMs, CUSUM, and autoencoder-style methods
  • Treated model utility and signal hygiene as core objectives, not just accuracy metrics
